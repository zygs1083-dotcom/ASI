# ASI

一组 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 插件，合起来构成一套 ASI 系统。每个插件安装后出现在 DSH 左侧栏。

| 插件 | 作用 | 状态 |
|---|---|---|
| `asi-sense` | 环境感知与触发：持续观察应用/窗口/文件/任务变化，维护"自身与环境状态"，决定哪些变化值得告诉或唤醒 agent | 设计中（见 [docs/DESIGN.md](docs/DESIGN.md)） |

协作规则见 [AGENTS.md](AGENTS.md)。
